Калькулятор раскроя плоского листа

Расчёт, общий итог и чертёж раскладки разверток на листе.

Исходные данные

У каждого изделия можно задать свою ширину листа. По умолчанию — 1250 мм. Изделия с одинаковой шириной листа кроятся совместно.
Без учёта толщины реза, технологических припусков и брака. Длина каждого листа/ряда берётся по самой длинной заготовке в этом ряду.

Чертёж раскладки разверток на листе

Чертёж строится по уникальным вариантам раскладки. Размеры на схеме пропорциональны реальным размерам; при печати используется заданный масштаб.

Формулы

1) Изделия группируются по одинаковой ширине листа.
2) Внутри группы заготовки сортируются: сначала по длине от большей к меньшей, затем по ширине от большей к меньшей.
3) Заготовка ставится в первый ряд, где хватает остатка по ширине.
4) Длина ряда = максимальная длина заготовки в этом ряду.
5) Площадь ряда = ширина листа / 1000 × длина ряда / 1000.
6) Полезная площадь ряда = сумма(ширина заготовки / 1000 × длина заготовки / 1000).
7) Обрезки = площадь ряда - полезная площадь ряда.
